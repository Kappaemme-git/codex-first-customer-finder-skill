# Output contract

Phase 1 JSON separates campaign configuration, durable company identity, discovery event, dated signals, score snapshot, duplicate decision, rejection decision, result, and run summary. This preserves boundaries needed for later Unreal OS storage without implementing a database.

All outcomes remain in the report, including rejected, suppressed, duplicate, relationship, and re-engagement decisions. Reports validate before rendering, escape untrusted text, accept only credential-free HTTP(S) links, and state that no creative or outreach occurred.
