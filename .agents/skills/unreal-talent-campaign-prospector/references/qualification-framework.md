# Unreal Talent qualification framework

Score each dimension from 0–5:

| Dimension | Weight |
| --- | ---: |
| Campaign and talent fit | 20 |
| Budget likelihood | 20 |
| Current trigger | 20 |
| Rights and organizational readiness | 15 |
| Brand and roster compatibility | 10 |
| Decision-path reachability | 10 |
| Evidence quality | 5 |

`88–100` priority, `78–87` qualified, `65–77` watchlist, `50–64` weak, below `50` reject. Qualified opportunities require official evidence, a current trigger, a talent-powered use case, budget uncertainty, rights/brand-safety caution, buyer path, canonical identity, score breakdown, and dated sources.
