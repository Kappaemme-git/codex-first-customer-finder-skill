# UMG qualification framework

Score each dimension from 0–5:

| Dimension | Weight |
| --- | ---: |
| Creative need | 20 |
| Product and visual fit | 20 |
| Budget likelihood | 15 |
| Marketing activity | 15 |
| Timing | 15 |
| Reachability | 10 |
| Evidence quality | 5 |

`85–100` priority, `72–84` qualified, `60–71` watchlist, `45–59` weak, below `45` reject. A qualified record needs an official source, current signal, canonical domain, explicit UMG use case, score breakdown, uncertainty, discovery date, and source date when available. Do not present inferred budget as fact.
