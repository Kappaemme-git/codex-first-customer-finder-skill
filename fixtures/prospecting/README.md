# Synthetic Phase 1 fixtures

All names, domains, handles, signals, campaigns, and outcomes in this directory are synthetic. Do not replace them with personal contact information or live prospect records.

- `campaigns/`: required open, vertical, multi-vertical, agency, and re-engagement examples.
- `history/`: durable local history covering identity, relationship, outreach, client, partner, suppression, cooldown, signal, score, and rejection state.
- `candidates/`: normalization, duplicate, re-engagement, and rights test inputs.
- `expected/`: expected duplicate decisions and complete sample run reports.

Campaign history paths are resolved relative to each campaign file by the validator.
